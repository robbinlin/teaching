這一步把影片裡出現的數字自己算一遍。每一節用一張講義表格：先照步驟用計算機算，再用 Excel 驗算。本章所有的變異數和標準差都除以 N−1（Excel 的 VAR.S、STDEV.S），這樣才會和講義印的數字一致。

## 用表 6-1 拆解變異數，算出信度

要算的是：觀察變異數、真實變異數、誤差變異數，以及信度。資料檔是 table6-1_sbp.csv，四欄依序是受試者、觀察的血壓、真實的血壓、誤差分數，共十個人。

### 手算步驟

1. 先核對誤差分數＝觀察−真實。例如 7 號：135−125＝＋10。十個誤差加起來是 0，所以觀察和真實的平均數都是 1250÷10＝125.0。
2. 算每一欄的離均差平方和：每個數字減掉平均數、平方、再加總。
3. 離均差平方和除以 N−1＝9，得到變異數。
4. 信度＝真實變異數÷觀察變異數。

| 統計量 | 觀察的血壓 | 真實的血壓 | 誤差分數 |
|---|---|---|---|
| 總和 | 1250 | 1250 | 0 |
| 平均數 | 125.0 | 125.0 | 0 |
| 離均差平方和 | 1202 | 1050 | 152 |
| 變異數（÷9） | 133.56 | 116.67 | 16.89 |
| 標準差 | 11.56 | 10.80 | 4.11 |

檢查：116.67＋16.89＝133.56，真實變異數加誤差變異數剛好等於觀察變異數。信度＝116.67÷133.56＝0.8735，四捨五入是 **0.87**。

### Excel 做法

用 Excel 開啟 table6-1_sbp.csv，資料在第 2 到第 11 列，B 欄是觀察、C 欄是真實、D 欄是誤差。在空白儲存格依序輸入：

```
=VAR.S(B2:B11)
=VAR.S(C2:C11)
=VAR.S(D2:D11)
=VAR.S(C2:C11)/VAR.S(B2:B11)
```

四格的結果是 133.56、116.67、16.89、0.8735。如果改用 VAR.P（除以 N），三個變異數會變成 120.2、105.0、15.2，和講義印的不一樣，所以講義用的是除以 N−1。

解讀：這十個人量到的血壓有高有低，其中約 87% 的差異是真的差異，13% 是測量誤差造成的。

## 用表 6-2 算再測信度

現實中沒有「真實的血壓」那一欄，所以改成同一個測驗測兩次，用兩次成績的相關係數當作信度。資料檔是 table6-2_situp.csv：十位受試者兩次仰臥起坐的次數。

### 手算步驟

1. 總和：測驗 1 是 413、測驗 2 是 418（講義這一列印成 41.3、41.8，那是平均數）。平均數＝41.3、41.8。
2. 離均差平方和：測驗 1 是 392.1，測驗 2 是 375.6。各除以 9 得到變異數 43.57、41.73，開根號得到標準差 6.60、6.46。
3. 離均差交乘積和：每個人「測驗 1 減平均」乘上「測驗 2 減平均」，加總是 355.6。
4. 相關係數＝355.6÷√(392.1×375.6)＝355.6÷383.76＝**0.927**。算法和第 4 章完全一樣，只是這裡的 X 和 Y 是同一個測驗的兩次成績。

### Excel 做法

B 欄是測驗 1、C 欄是測驗 2，資料在第 2 到第 11 列：

```
=SUM(B2:B11)
=AVERAGE(B2:B11)
=STDEV.S(B2:B11)
=CORREL(B2:B11,C2:C11)
```

結果是 413、41.3、6.60、0.9266。把 B 換成 C 再做一次，得到測驗 2 的 418、41.8、6.46。

解讀：再測信度 0.927，表示十個人兩次測驗的高低順序幾乎沒有變，這個測驗量得很穩。

### 相關的盲點：表 6-5 每個人都多 10 分

打開 table6-5_plus10.csv，同樣用 CORREL 算兩次測驗的相關，再用 AVERAGE 算兩次的平均數：

```
=CORREL(B2:B11,C2:C11)
=AVERAGE(B2:B11)
=AVERAGE(C2:C11)
```

相關是 1.00，平均數卻是 23.3 和 33.3。第二次每個人都多了 10 分，相關係數完全看不出來，因為它只看每個人的相對位置。所以「相關很高」只能說兩次的排序一致，不能說兩次的數字一樣；這也是最後一節要用 Bland-Altman 圖的原因。

## 用表 6-3 算折半信度，再做 Spearman-Brown 校正

折半信度只需要考一次：把題目拆成奇數題和偶數題，各算一個分數，再算兩半的相關。資料檔是 table6-3_oddeven.csv。

### 手算步驟

1. 奇數分數總和 92、平均 9.2；偶數分數總和 86、平均 8.6。
2. 離均差平方和：奇數 43.6、偶數 60.4（變異數 4.84、6.71，標準差 2.20、2.59）；離均差交乘積和 32.8。
3. 兩半的相關＝32.8÷√(43.6×60.4)＝32.8÷51.32＝**0.639**。
4. 這個 0.639 只是「半份測驗」的信度。用 Spearman-Brown 公式校正回完整長度（長度變成 2 倍，k＝2）：2×0.639÷(1＋0.639)＝1.278÷1.639＝**0.78**。

公式的一般寫法是：新信度＝k×r÷[1＋(k−1)×r]，k 是長度變成原來的幾倍。講義第 10、11 張的表 6-4 就是用這個公式算好的對照表：在左邊找 r＝0.64 那一列，往右找 k＝2.00 那一欄，查到 0.78。同一列 k＝3.00 是 0.84，k＝0.50 是 0.47，測驗加長信度變高，縮短就變低。

### Excel 做法

```
=CORREL(B2:B11,C2:C11)
=2*CORREL(B2:B11,C2:C11)/(1+CORREL(B2:B11,C2:C11))
```

結果是 0.6392 和 0.7799。

解讀：這份測驗的折半信度要報告 0.78，不是 0.639。影片的小考也是同一個算法：折半相關 0.50，校正後是 2×0.50÷1.50＝0.67。

## 用表 6-6 算 alpha 係數

同一個測驗測了三次以上，可以不用兩兩算相關，直接用變異數算 alpha 係數。資料檔是 table6-6_alpha.csv：五位受試者、三次測驗，最後一欄是三次的總分。

### 手算步驟

1. 每一欄先算 ΣX 和 ΣX²（講義表 6-6 已經列出來）。
2. 變異數＝[ΣX²−(ΣX)²÷n]÷(n−1)，這裡 n＝5。例如測驗 1：(83−19²÷5)÷4＝(83−72.2)÷4＝2.70。
3. 把三次測驗的變異數加起來：2.70＋1.70＋1.30＝5.70。
4. alpha＝k÷(k−1)×(1−各次變異數的和÷總分變異數)，k 是測驗次數 3：3÷2×(1−5.70÷9.50)＝1.5×0.40＝**0.60**。

| 統計量 | 測驗 1 | 測驗 2 | 測驗 3 | 總分 |
|---|---|---|---|---|
| ΣX | 19 | 19 | 17 | 55 |
| ΣX² | 83 | 79 | 63 | 643 |
| 變異數 | 2.70 | 1.70 | 1.30 | 9.50 |

### Excel 做法

B、C、D 欄是三次測驗，E 欄是總分，資料在第 2 到第 6 列：

```
=VAR.S(B2:B6)+VAR.S(C2:C6)+VAR.S(D2:D6)
=VAR.S(E2:E6)
=3/2*(1-(VAR.S(B2:B6)+VAR.S(C2:C6)+VAR.S(D2:D6))/VAR.S(E2:E6))
```

結果是 5.70、9.50、0.60。SPSS 的做法是 Analyze → Scale → Reliability Analysis，把三次測驗放進 Items，Model 選 Alpha（中文版的選單名稱依版本不同，在「分析」底下找「信度分析」）。

解讀：如果同一個人三次的分數都一起高、一起低，總分的變異數會比各次變異數的和大很多，alpha 就接近 1。這份資料的 alpha 只有 0.60，表示三次測驗之間還不夠一致。

## 算測量標準誤

信度是整群人的指標。想知道「一個人的分數要加減多少來看」，要算測量標準誤：標準差×√(1−信度)。這一節用表 6-2 測驗 1（table6-2_situp.csv）的結果。

### 手算步驟

1. 測驗 1 的標準差是 6.6，再測信度是 0.927。
2. 1−0.927＝0.073，開根號是 0.270。
3. 測量標準誤＝6.6×0.270＝**1.78**，約 1.8 下。
4. 1 號第一次做 45 下：45±1.8 是 43.2 到 46.8 下；45±2×1.8 是 41.4 到 48.6 下。

### Excel 做法

```
=STDEV.S(B2:B11)*SQRT(1-CORREL(B2:B11,C2:C11))
```

結果是 1.79。它和手算的 1.78 差在 Excel 用的是還沒四捨五入的標準差（6.6005）和相關（0.9266），兩個答案都約 1.8 下。

解讀：測量標準誤可以想成「誤差分數的標準差」。照第 3 章常態分配的規則，真實分數大約有 68% 的機會落在觀察分數加減 1 個測量標準誤之內，約 95% 落在加減 2 個之內。信度越高，測量標準誤越小。

想驗證「測量標準誤就是誤差分數的標準差」，可以回到表 6-1：觀察分數的標準差 11.56、信度 0.8735，11.56×√(1−0.8735)＝4.11，正好等於第一節算出來的誤差分數標準差 4.11。

## 用表 6-9 畫 Bland-Altman 圖，算一致性界限

要比較兩種量法的數字一不一致，每個人要算兩個數字：差值和平均。資料檔是 table6-9_bland_altman.csv，B 欄是水銀柱血壓計、C 欄是自動電子血壓計；D 欄「誤差」就是差值，E 欄是平均。

### 手算步驟

1. 差值＝電子−水銀柱。例如 7 號：125−135＝−10。十個差值是 2、−2、4、2、−2、0、−10、4、2、0。
2. 平均＝(電子＋水銀柱)÷2。例如 7 號：(125＋135)÷2＝130。
3. 平均差＝十個差值的總和÷10＝0÷10＝0。
4. 差值的平方和是 152，除以 9 得到變異數 16.89，開根號得到標準差 4.11。
5. 一致性界限＝平均差±1.96×標準差＝0±1.96×4.11＝0±8.06，四捨五入是 **−8.1 到 ＋8.1**。標準差要留到 4.11 再乘；用 4.1 去乘會得到 8.04，四捨五入後差了 0.1。
6. 逐一比對：只有 7 號的 −10 超出界限，其他 9 個人都在界限內。

1.96 是常態分配的數字：平均數加減 1.96 個標準差，涵蓋中間 95% 的值（第 3 章）。所以界限的意思是：同一個人換一台血壓計量，兩台的差距大約有 95% 會落在這個範圍裡。

### Excel 做法

在 F2 輸入差值的公式、G2 輸入平均的公式，往下複製到第 11 列：

```
=C2-B2
=(B2+C2)/2
```

再用下面四個公式算平均差、標準差、下界、上界：

```
=AVERAGE(F2:F11)
=STDEV.S(F2:F11)
=AVERAGE(F2:F11)-1.96*STDEV.S(F2:F11)
=AVERAGE(F2:F11)+1.96*STDEV.S(F2:F11)
```

結果是 0、4.11、−8.05、8.05。畫圖：選取 G 欄（平均）和 F 欄（差值），插入散佈圖，橫軸就是平均、縱軸就是差值；再用「插入」裡的線條圖案，在平均差和上下界的高度各畫一條水平線。

解讀：平均差是 0，表示沒有哪一台固定偏高；界限 ±8.1，表示兩台的差距大多在 8 mmHg 以內。這個差距能不能接受，要由使用的人依用途判斷。

眼尖的話會發現：表 6-9 的數字就是表 6-1 的數字，水銀柱那一欄是「觀察的血壓」，電子那一欄是「真實的血壓」。所以差值的標準差 4.11，和第一節誤差分數的標準差是同一個數字。

### 換成表 6-10 再算一次

打開 table6-10_bland_altman.csv，照同樣的步驟做。5、7、9 號的數字改過了，差值變成 −22、−26、＋18。

| 統計量 | 表 6-9 | 表 6-10 |
|---|---|---|
| 差值總和 | 0 | −20 |
| 平均差 | 0 | −2.0 |
| 差值標準差 | 4.11 | 12.86 |
| 一致性界限 | −8.1 到 ＋8.1 | −27.2 到 ＋23.2 |
| 落在界限外 | 7 號 | 沒有人 |
| 兩台的相關 r | 0.935 | 0.607 |

表 6-10 的界限＝−2.0±1.96×12.86＝−2.0±25.2。界限以平均差 −2.0 為中心，所以上下不對稱。差到二十幾 mmHg，影片的結論是這兩台血壓計不能互相替換。

### 講義要更正的地方
