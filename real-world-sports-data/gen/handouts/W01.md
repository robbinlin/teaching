# 第 1 週　課程介紹：AI 會寫程式之後，分析者做什麼

## 本週要回答的問題

語言模型能在幾秒內寫出資料分析程式。那麼一門資料分析課該教什麼，你該學什麼？

## 時間配置

| 時段 | 內容 |
|---|---|
| 第 1 節 | 現場示範：同一題、兩個答案 |
| 第 2 節 | 課程架構、評分、AI 使用規範 |
| 第 3 節 | 環境設定與課堂任務 |

## 講授重點

### 1. 現場示範：同一題、兩個答案

題目只有一句話：「都市化程度和學生規律運動有沒有關係？」

把主資料集與這句話交給 AI 助理，重開對話再問一次（或換一個模型）。把兩次的結果並排，逐項比對下列五個決策。學生會看到，模型沒有問你，就替你做了決定：

| 決策 | 模型可能的做法 A | 模型可能的做法 B |
|---|---|---|
| 「規律運動」怎麼定義 | 每週運動 3 天以上 | 每週 3 天以上，且運動時會流汗會喘 |
| 遺漏值（編碼 -1）怎麼辦 | 當作一般數值留在資料裡 | 轉成遺漏後刪除 |
| 沒回答的人算不算分母 | 算，歸為「不規律」 | 不算 |
| 「都市化」怎麼分 | 六都對非六都 | 依縣市分成數層 |
| 用什麼方法 | 卡方檢定 | 邏輯斯迴歸 |

兩份結果都附有程式、圖表與流暢的文字說明，看起來都對。比例可能差好幾個百分點。

### 2. 三件留給人的事

程式由誰寫已經不重要。下列三件事，模型做不好，或做了也必須由你負責：

- **規格**：把上面五個決策在分析之前寫下來。
- **判斷**：這份橫斷面調查能不能回答「有沒有關係」背後真正想問的問題。
- **驗證**：確認程式做的事等於你以為它做的事。

本學期十六週的內容都落在這三件事上。

### 3. 課程架構

| 單元 | 週次 | 核心能力 |
|---|---|---|
| 問題與規格 | 1–3 | 把問題寫成可執行的規格 |
| 讀程式與驗證 | 4–6 | 審查程式、找出錯誤 |
| 描述與推論 | 7–10 | 選方法、讀結果 |
| 預測 | 11–12 | 避免資料洩漏、檢查穩定性 |
| 因果 | 13–15 | 處理混淆、說明限制 |
| 報告 | 16–18 | 可重跑、可揭露 |

### 4. 評分與規範

見課綱第三、四、五節。課堂上特別說明三點：

- 每週驗證紀錄是一頁紙，不是心得。格式固定：規格、AI 產出、我做的檢查、發現的問題、結論。
- 期中與期末的口頭答詢不能使用 AI。
- 主資料集的原始檔不得轉傳，也不得放到公開位置。

## 課堂任務（40 分鐘）

1. 每人用自己選定的 AI 助理，對主資料集提出示範題的那一句話，不加任何補充。
2. 把模型對五個決策的做法，以及最後報告的「規律運動比例」，填入班級共用表格。
3. 全班檢視表格：有幾種不同的定義？比例的最大與最小差多少？
4. 每組挑一個決策，討論哪一種做法比較合理，需要什麼資訊才能決定。

## 搭配工具

AI 助理（Claude、ChatGPT、Gemini 任兩個）；班級共用試算表。

## 課後作業

完成環境設定。寫下課堂任務中你自己的模型與鄰座的模型差異最大的一個決策，以及你認為哪一個比較合理（半頁）。

## 教師備註

- 示範前先自己跑兩到三次，留下差異最明顯的兩份輸出作為備案，避免現場兩次結果剛好一致。
- 開學前先確認 SRDA 使用約定是否允許把原始檔上傳到雲端 AI 服務。若不允許，示範與課堂任務改用教師準備的合成資料檔（變項結構相同、數值為模擬），或改在本機執行。
- 不要在這一週解釋哪個做法才對。第 3 週寫規格書、第 6 週談驗證時會回到同一題。
