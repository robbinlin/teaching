## 講授重點

### 1. 同一件事，三種語言

任務：把主資料集中編碼為 -1 的答案改成遺漏值。

SAS（課程既有程式）：

```sas
data survey2;
  set survey;
  array vars {*} a1-a6 b1-b8 b9_2 b10_1 b13-b21;
  do i = 1 to dim(vars);
    if vars[i] = -1 then vars[i] = .;
  end;
  drop i;
run;
```

R：

```r
survey2 <- survey |>
  mutate(across(c(a1:a6, b1:b8, b9_2, b10_1, b13:b21),
                ~ na_if(.x, -1)))
```

Python：

```python
cols = ["a1","a2","a3","a4","a5","a6","b9_2","b10_1"] \
     + [f"b{i}" for i in range(1, 9)] \
     + [f"b{i}" for i in range(13, 22)]
survey2 = survey.copy()
survey2[cols] = survey2[cols].replace(-1, np.nan)
```

三段程式的結構相同：指定一組欄位，逐欄把 -1 換成遺漏。讀程式時先找這兩件事：**作用在哪些欄位**、**做了什麼替換**。這份清單沒有包含 `b9_1a`、`b9_1b`、`b9_1c`，它們的 -1 還在。

### 2. 審查五問

每拿到一段清理程式，依序回答：

1. 讀進幾列、幾欄？和編碼簿記載的一致嗎？
2. 每一欄的型態對嗎？應該是數值的欄位有沒有被讀成文字？
3. 遺漏碼處理了哪些欄位？漏了哪些？
4. 每一步之後，遺漏值增加了幾筆？列數減少了幾列？
5. 有沒有哪一步在沒有訊息的情況下刪掉資料？

第 4、5 問的答案不在程式裡，在輸出與紀錄檔裡。只看程式不看紀錄檔，等於沒有審查。

### 3. 四個語言陷阱

**陷阱一：遺漏值的比較，三種語言三種結果。**

| 敘述 | 遇到遺漏值時 |
|---|---|
| SAS `if x < 3` | 成立。SAS 把數值遺漏視為比任何數都小 |
| R `filter(x < 3)` | 比較結果為 `NA`，該列被丟掉 |
| pandas `df[df.x < 3]` | 比較結果為 `False`，該列被丟掉 |

把一段 SAS 程式請 AI 翻成 R，邏輯看似相同，樣本數可能不同。

**陷阱二：文字轉數值失敗時不會停下來。**

```sas
temp1 = input(b9_1b, best32.);
```

無法轉換的內容變成遺漏，SAS 只在紀錄檔留下一行 NOTE。R 的 `as.numeric()` 給一則警告。pandas 的 `pd.to_numeric(errors="coerce")` 完全沒有訊息。轉換前後各算一次遺漏數。

**陷阱三：去重留下哪一筆。**

```sas
proc sort data=readin nodupkey; by id; run;
```

`nodupkey` 只比對 `id`，同一個 `id` 留下排序後的第一筆，其餘刪除，即使其他欄位內容不同。`nodup` 則要求整列相同。課程範例資料中，ID 1 的 David 有 45 分與 74 分兩筆，`nodupkey` 之後只剩一筆。刪除之前先看重複的是什麼。

**陷阱四：日期的月與日。**

`01/02/2019` 是一月二日還是二月一日，取決於系統設定（SAS 的 `DATESTYLE`），不取決於資料。讀入日期後，檢查最小值、最大值，以及「日」大於 12 的筆數是否合理。

### 4. 標準化、常態化：先對齊名詞

| 名稱 | 公式 | 結果範圍 | SAS |
|---|---|---|---|
| Min-max 縮放 | (x − min) / (max − min) | 0 到 1 | `proc stdize method=range` |
| Z 分數標準化 | (x − 平均) / 標準差 | 平均 0、標準差 1 | `proc stdize method=std` |
| 占比 | x / 總和 | 加總為 1 | 以 `proc sql` 計算 |

中文的「正規化」「歸一化」「標準化」在不同教材指不同的東西。對 AI 下指令時直接寫公式，不要只寫名稱。

## 課堂任務（60 分鐘）

下面是 AI 依「幫我清理這份資料」產生的程式。它可以執行，沒有錯誤訊息。請用審查五問找出問題，逐項寫出：問題在哪一行、後果是什麼、如何用輸出證明、如何修正。

```r
survey <- read_csv("data108.csv")

clean <- survey |>
  mutate(across(b13:b21, ~ na_if(.x, -1))) |>
  mutate(b9_1b = as.numeric(b9_1b)) |>
  distinct(id, .keep_all = TRUE) |>
  drop_na()

nrow(clean)
```

（`id` 請替換為編碼簿中的受訪者編號變項。）

## 教師備註

課堂任務的四個問題：

1. `across(b13:b21, …)` 只處理九題，其餘欄位的 -1 仍被當作數值。
2. `as.numeric(b9_1b)` 轉換失敗會變成 `NA`，程式沒有回報筆數。
3. `distinct(id, .keep_all = TRUE)` 在未檢查重複內容的情況下保留第一筆。
4. `drop_na()` 只要任何一欄遺漏就刪除整列，樣本數會大幅縮減，而且沒有訊息。
