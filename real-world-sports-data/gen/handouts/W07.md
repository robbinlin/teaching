# 第 7 週　探索式資料分析與視覺化

## 本週要回答的問題

建模之前，要先從資料裡看到什麼？一張圖怎樣算是誠實？

## 時間配置

| 時段 | 內容 |
|---|---|
| 第 1 節 | 表一、遺漏型態、離群值 |
| 第 2 節 | 調查權重；圖的選擇與誤導 |
| 第 3 節 | 課堂任務：表一與三張圖 |

## 講授重點

### 1. 為什麼先看資料

Anscombe（1973）造了四組資料，平均、變異數、相關係數、迴歸線幾乎相同，畫出來是四種完全不同的形狀。摘要統計量相同不代表資料相同。請 AI 做分析時，先要分布與圖，再要模型。

### 2. 表一

表一依主要分組變項（例如規律運動與否）列出樣本特徵。它回答三個問題：樣本是誰、兩組在哪些地方不同、每個變項缺多少。

| 變項型態 | 報告方式 |
|---|---|
| 連續、近似對稱 | 平均（標準差） |
| 連續、偏態 | 中位數（四分位距） |
| 類別 | 人數（百分比），註明分母 |
| 所有變項 | 遺漏人數 |

R 的 `gtsummary::tbl_summary()` 一行可以產生。產生之後手算其中一格。

### 3. 遺漏型態

- 每個變項缺多少，是第一層。
- 哪些人缺，是第二層：遺漏是否集中在某個年級、某類學校？
- 跳答造成的「遺漏」不是遺漏，是不適用，不應補值也不應刪除。

完整個案分析會留下多少人，在第 4 週的列數帳就該知道。

### 4. 離群值不等於錯誤

課程既有的兩個巨集代表兩種思路：

| | `%Errors` | `%Auto_Outliers` |
|---|---|---|
| 判斷依據 | 你給定的合理上下限 | 截尾後的平均 ± 數個標準差 |
| 需要什麼 | 領域知識 | 不需要，但偏態資料會誤判 |
| 適合 | 有明確合理範圍的變項 | 初步掃描 |

被標出的值有三種可能：輸入錯誤、遺漏碼、真實的極端值。只有前兩種該處理。每週運動 20 小時的學生可能是校隊。刪除之前回到原始紀錄確認，並在列數帳中記錄。

### 5. 調查權重

主資料集來自抽樣調查。未加權的比例描述的是樣本，加權的比例估計的是母體。兩者差多少，取決於抽樣時各層的抽出率差多少。

```r
library(survey)
des <- svydesign(ids = ~1, weights = ~wt, data = survey4)
svymean(~regular, des, na.rm = TRUE)
svyby(~regular, ~urban, des, svymean, na.rm = TRUE)
```

（`wt` 請替換為編碼簿中的權重變項；若有分層與叢集變項，一併放入 `svydesign`。）

SAS 對應的是 `PROC SURVEYFREQ` 與 `PROC SURVEYMEANS`。AI 幾乎不會主動加權，除非你在規格書中寫明。

### 6. 選圖

| 想呈現 | 圖 |
|---|---|
| 一個連續變項的分布 | 直方圖、箱形圖 |
| 各組的比例 | 長條圖（y 軸從 0 開始），附信賴區間 |
| 兩個連續變項的關係 | 散布圖，樣本大時加透明度 |
| 各縣市的數值 | 分級著色地圖，附數值標籤 |
| 隨時間的變化 | 折線圖 |

### 7. 四種常見的誤導

1. **統計量不是你以為的那個。** 第 6 週的案例三：軸標籤寫百分比，柱高是人數。
2. **截斷的 y 軸。** 62% 與 65% 的長條，若 y 軸從 60 開始，看起來差了一倍以上。
3. **立體效果與雙 y 軸。** 立體柱的高度難以比較；雙軸的刻度可以任意調整出想要的交叉。
4. **只畫平均不畫變異。** 兩組平均差 0.1 分，分布幾乎完全重疊，長條圖看不出來。

### 8. 請 AI 畫圖時的規則

要求它同時輸出圖背後的摘要表。圖上任取一個數字，與表格核對。每張圖配一句話，說明它回答什麼問題；說不出來的圖刪掉。

## 課堂任務（60 分鐘）

1. 依規律運動與否製作表一，包含人口學變項、都市化層級與體育學習認知九題。
2. 製作三張圖：一張分布、一張分組比例、一張自選。每張圖寫一句「這張圖回答的問題」。
3. 與另一組交換。審查對方的表與圖：手算一格、核對一個圖上數字、指出一處可改進的地方。
