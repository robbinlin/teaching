# 第 16 週　報告、可重現性與 AI 使用揭露

## 本週要回答的問題

別人拿到你的資料夾，按一個鍵，能不能得到和你報告裡一樣的數字？

## 講授重點

### 1. 複製貼上是錯誤的來源

傳統流程：在統計軟體跑出結果，把數字抄進文書軟體。資料更新或定義修改之後，要重新抄一次，總有幾個數字忘了改。第 9 週期中報告裡「內文與表格數字不一致」就是這樣來的。

Quarto 把文字、程式與輸出放在同一份文件。文中的數字由程式在產生文件時填入：

```markdown
分析樣本共 `r nrow(d)` 人，其中規律運動者占
`r round(100 * mean(d$regular, na.rm = TRUE), 1)`%。
```

資料或定義改了，重新產生文件，所有數字一起更新。

### 2. 專案資料夾

```
project/
├── README.md          專案說明、執行順序、軟體版本
├── data/
│   ├── raw/           原始資料，唯讀，不修改
│   └── derived/       程式產生的資料
├── code/
│   ├── 01_clean.R
│   ├── 02_analysis.R
│   └── 03_figures.R
├── output/            表格與圖
├── log/               AI 對話與執行紀錄
└── report/
    └── report.qmd
```

三條規則：原始資料不動；衍生資料只由程式產生；程式檔名有順序。

### 3. 重跑測試

把資料夾交給另一個人（或一個全新的 AI 對話），只給 `README.md`。對方能否：

1. 不問你任何問題就執行完畢？
2. 得到與報告相同的數字？

常見的失敗原因：寫死的個人路徑（`D:\Dropbox\...`）、沒有記錄的套件、手動做過但沒寫進程式的步驟、沒有設定亂數種子。

### 4. 報告規範

| 規範 | 適用 | 重點項目 |
|---|---|---|
| STROBE | 觀察性研究 | 研究設計、納入排除、變項定義、遺漏處理、偏誤、限制 |
| RECORD | 使用例行蒐集資料的研究 | 資料來源、連結方式、編碼與演算法、資料清理 |
| TRIPOD+AI | 預測模型 | 資料切分、前處理、表現指標、校準 |

把檢核表當作繳交前的最後一次自我審查。每一項標上報告中的頁碼；標不出來的就是漏寫的。

### 5. AI 使用揭露

主要期刊的共同立場：AI 不能列為作者；使用須揭露；作者對全部內容負責。

揭露要具體到讀者能判斷風險。四個要素：

| 要素 | 例子 |
|---|---|
| 工具與版本 | 工具名稱、模型版本、使用日期 |
| 用在哪裡 | 撰寫資料清理與分析程式；起草結果段落 |
| 沒用在哪裡 | 研究問題、DAG 與調整集、結論由作者決定 |
| 人做了什麼驗證 | 所有衍生變項經交叉表檢查；主要結果以 JASP 獨立重現；所有引用經作者核對原文 |

不好的寫法：「本研究使用 AI 工具輔助。」

### 6. 互動式呈現

課程既有的 `dashboard.py` 用 Streamlit 把幸福感資料做成可互動的儀表板。什麼時候值得做：

- 讀者想查自己關心的那一個縣市或那一所學校。
- 資料會持續更新。

什麼時候不值得：只是為了一次報告。靜態的表與圖更容易審查，也更容易重現。

儀表板裡的每個數字一樣要通過第 6 週的檢查。請 AI 做儀表板時，它常在頁面裡重新寫一次資料處理邏輯，與報告用的程式不一致。儀表板應讀取 `data/derived/` 的結果，不另外計算。

### 7. 期末專案驗收清單

**規格與設計**

- [ ] 問題類型明確（描述、預測、因果）
- [ ] 規格書於分析前完成，修改處有紀錄

**資料與驗證**

- [ ] 列數帳：從原始資料到分析樣本
- [ ] 每個衍生變項有交叉表
- [ ] 至少一個主要結果由第二條路徑重現

**方法與結果**

- [ ] 方法與問題類型相符
- [ ] 報告效果量與信賴區間
- [ ] 因果題：DAG、平衡診斷、敏感度分析
- [ ] 預測題：基準模型、洩漏檢查、校準
- [ ] 描述題：權重、母體界定

**報告**

- [ ] 他人可依 README 重跑
- [ ] 限制段落指出偏誤方向
- [ ] AI 使用揭露包含四個要素
- [ ] 所有引用經核對

## 課堂任務（70 分鐘）

1. 各組把期末專案目前的分析整理成上述資料夾結構，報告改為 Quarto 文件（30 分鐘）。
2. 與另一組交換資料夾。在自己的電腦上依 README 重跑，不可詢問對方（25 分鐘）。
3. 回報：是否執行成功、數字是否一致、卡在哪裡（15 分鐘）。

資料不能交換時（自備資料有使用限制），改交換程式與一份合成資料。
