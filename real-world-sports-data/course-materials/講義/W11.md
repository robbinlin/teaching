# 第 11 週　監督式學習：預測模型

## 本週要回答的問題

模型在手上這份資料表現很好。它在沒看過的資料上也會好嗎？

## 時間配置

| 時段 | 內容 |
|---|---|
| 第 1 節 | 預測任務的定義；切分與交叉驗證 |
| 第 2 節 | 資料洩漏；評估指標 |
| 第 3 節 | 課堂任務：基準模型與洩漏 |

## 講授重點

### 1. 先定義預測任務

寫模型之前回答四題：

1. 預測什麼？（不規律運動：是或否）
2. 在什麼時間點預測？那個時間點已經知道哪些資訊？
3. 預測出來之後要做什麼？（例如優先邀請參加體育活動）
4. 錯誤的代價：漏掉一位需要協助的學生，與多邀請一位不需要的學生，哪個嚴重？

第 2 題決定哪些變項可以當特徵。第 4 題決定門檻怎麼設。

### 2. 切分與交叉驗證

| 資料 | 用途 | 規則 |
|---|---|---|
| 訓練集 | 配適模型 | — |
| 驗證集或交叉驗證 | 選模型、調參數 | 可以重複使用 |
| 測試集 | 報告最終表現 | 只用一次，最後才打開 |

固定亂數種子，寫進紀錄。同一所學校的學生彼此相似，若資料有學校代碼，應以學校為單位切分。

### 3. 資料洩漏

洩漏是指模型在訓練時用到了預測當下不該知道的資訊。結果是測試表現虛高，實際使用時失效。Kapoor 與 Narayanan（2023）整理了 17 個領域、近三百篇受洩漏影響的論文。

| 類型 | 例子 | 檢查方式 |
|---|---|---|
| 特徵包含結果的成分 | 用「運動時會流汗會喘」預測規律運動，而規律運動的定義就包含這一題 | 逐一核對特徵與結果的定義 |
| 特徵是結果的後果 | 用運動後才形成的態度預測運動 | 問：預測當下這個值存在嗎 |
| 前處理在切分之前 | 用全部資料算平均來標準化或補值 | 前處理必須包在交叉驗證裡面 |
| 同一單位跨越兩邊 | 同一位學生的多筆紀錄分在訓練與測試 | 以個人或學校為單位切分 |
| 重複使用測試集 | 看了測試結果後回頭調整模型 | 測試集只打開一次 |

AI 交出的流程若區辨力接近完美，先懷疑洩漏，再考慮是不是模型真的很好。

### 4. 從簡單的模型開始

| 模型 | 特點 |
|---|---|
| 邏輯斯迴歸 | 基準。係數可檢查，不易過度配適 |
| 正則化邏輯斯迴歸 | 特徵多或彼此相關時較穩定 |
| 隨機森林 | 自動處理非線性與交互作用 |
| 梯度提升樹 | 表格資料上通常最準，需要調參 |

特徵只有十幾個的調查資料，複雜模型未必勝過邏輯斯迴歸。先建基準，複雜模型要贏過基準才值得用。

### 5. 評估：區辨與校準

- **區辨力**（ROC 曲線下面積）：模型能否把會發生與不會發生的人排開。
- **校準**：模型說 30% 的那群人，實際是不是約 30% 發生。畫校準圖。
- **在選定門檻下**：敏感度、特異度、陽性預測值。

區辨力高而校準差的模型，排序可以用，機率不能用。

### 6. 變項重要性不是原因

重要性與 SHAP 值說明模型用了哪些變項來預測，不說明改變那個變項會發生什麼。「運動態度是最重要的預測因子」不能改寫成「提升運動態度能增加規律運動」。

### 7. 最小可執行範例

```r
library(tidymodels)
set.seed(2027)
split <- initial_split(d, prop = 0.8, strata = irregular)
train <- training(split); test <- testing(split)

rec <- recipe(irregular ~ ., data = train) |>
  step_impute_median(all_numeric_predictors()) |>
  step_normalize(all_numeric_predictors())

wf <- workflow() |> add_recipe(rec) |> add_model(logistic_reg())
cv <- vfold_cv(train, v = 5, strata = irregular)
fit_resamples(wf, cv, metrics = metric_set(roc_auc, brier_class)) |>
  collect_metrics()
```

補值與標準化寫在 `recipe` 裡，每一折只用該折的訓練部分計算，這樣才不會洩漏。

## 課堂任務（60 分鐘）

1. 寫下預測任務的四題答案，列出可以用與不可以用的特徵（15 分鐘）。
2. 建立邏輯斯迴歸基準，以五折交叉驗證回報區辨力（15 分鐘）。
3. 教師提供一段 AI 寫的隨機森林流程，區辨力高得不合理。找出洩漏來源並修正（20 分鐘）。
4. 修正後與基準比較，畫校準圖（10 分鐘）。

## 檢核清單

- [ ] 每個特徵在預測當下都已存在
- [ ] 沒有特徵是結果定義的一部分
- [ ] 前處理在交叉驗證之內
- [ ] 有邏輯斯迴歸基準可比較
- [ ] 報告了校準，不只區辨力
- [ ] 測試集只用了一次

## 搭配工具

R `tidymodels` 或 Python `scikit-learn`（Google Colab）；AI 助理。

## 課後作業（驗證紀錄 9）

繳交洩漏修正前後的表現對照，以及基準模型與一個複雜模型在測試集上的區辨力與校準圖。用三句話說明這個模型能不能用、給誰用。
