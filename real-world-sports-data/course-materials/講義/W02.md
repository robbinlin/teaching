# 第 2 週　真實世界數據與三類研究問題

## 本週要回答的問題

拿到一份資料時，哪些問題它答得了，哪些答不了？

## 時間配置

| 時段 | 內容 |
|---|---|
| 第 1 節 | 真實世界數據的來源與特性 |
| 第 2 節 | 描述、預測、因果：三類問題 |
| 第 3 節 | 讀編碼簿、課堂任務 |

## 講授重點

### 1. 什麼是真實世界數據

真實世界數據不是為了你的研究問題而蒐集的。它來自行政作業、例行調查、裝置紀錄或賽事追蹤。這帶來兩個後果：變項的定義由別人決定；誰被納入資料由蒐集過程決定。

| 來源 | 例子 | 分析時要先問的事 |
|---|---|---|
| 例行調查 | 學生運動參與情形調查、運動現況調查 | 抽樣設計與權重；題目原文；回溯期間 |
| 行政與檢測資料 | 體適能檢測、健保申報 | 誰會被記錄、誰不會 |
| 穿戴裝置 | 心率、步數、GPS | 配戴的人是誰；未配戴的時段 |
| 賽事追蹤 | 逐球紀錄、球員追蹤 | 事件由誰、依什麼規則標記 |

### 2. 三類問題

Hernán 等人（2019）把資料科學的任務分成三類。同一份資料、同一組變項，問法不同，需要的方法與能下的結論都不同。

| | 描述 | 預測 | 因果 |
|---|---|---|---|
| 問法 | 現況是什麼 | 能不能由 X 猜到 Y | 改變 X，Y 會不會跟著變 |
| 主資料集的例子 | 各縣市學生規律運動比例是多少 | 能否由背景變項找出不規律運動的學生 | 參加運動社團會不會讓學生更規律運動 |
| 關鍵要求 | 樣本能代表母體（權重） | 模型在新資料上仍準確 | 比較的兩組在其他方面可比 |
| 典型方法 | 加權比例、信賴區間 | 迴歸、機器學習、交叉驗證 | DAG、傾向分數、敏感度分析 |
| 常見誤用 | 用未加權樣本推論全國 | 把重要變項解讀成原因 | 把相關寫成「影響」 |

論文題目裡的「影響」「效果」「造成」都是因果語言。用了這些詞，就要用因果的標準檢驗。

### 3. 讀編碼簿

分析之前，從編碼簿找出下列六項，寫進筆記：

1. 母體與抽樣方式（分層、叢集、權重變項名稱）
2. 題目原文與回溯期間（「上學期」或「過去七天」）
3. 選項與數值編碼的對應
4. 遺漏與不適用的編碼（本資料為 -1）
5. 跳答邏輯：哪些人不會被問到這一題
6. 衍生變項：釋出單位已經算好的欄位

模型看不到編碼簿時，會把 -1 當作數值，把類別代碼當作連續變項。

### 4. 用 AI 找文獻

| 工具 | 適合做什麼 |
|---|---|
| Elicit、Consensus | 以研究問題搜尋，回傳論文與摘要整理 |
| Scite | 查一篇論文被後續研究支持還是反駁 |
| PubMed | 確認論文確實存在、書目正確 |
| NotebookLM | 對自己上傳的全文提問，回答附原文位置 |

規則只有一條：寫進報告的每一筆引用，自己開過原文，說得出研究設計與主要結果。

每組打開主資料集的編碼簿，完成下表並口頭報告。

| 結果變項（題號與定義） | | | |
| 暴露或預測變項 | | | |
| 最擔心的問題 | | | |

接著請 AI 助理對同一份編碼簿提出三題，與本組的版本比較：模型提的因果題，資料真的答得了嗎？

## 常見錯誤

- 把預測模型的係數逐一解讀為各變項的效果。
- 忽略權重，把樣本比例直接當作全國比例。
- 沒注意回溯期間，把兩個時間範圍不同的題目放在一起比較。
- 引用模型提供的文獻而未確認其存在。

## 課後作業（驗證紀錄 1）

從課堂任務的三題中選一題。用文獻工具找三篇相關研究，為每一篇填寫：研究設計、樣本、主要結果、你確認原文的方式。標出其中一筆 AI 摘要與原文不一致之處；若沒有找到不一致，說明你檢查了哪些地方。
