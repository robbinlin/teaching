## 講授重點

### 1. 傾向分數是什麼

傾向分數是給定一個人的特徵之後，他接受處理的機率：e(X) = P(處理 = 1 | X)。

它的用處是降維。十幾個混淆因子無法逐一配對，但傾向分數相同的兩個人，這些因子的分布平均而言相同。把多個變項的平衡問題，變成一個分數的平衡問題。

傾向分數只能平衡放進模型的變項。沒測到的混淆因子，它無能為力。第 13 週畫的 DAG 決定了放什麼。

### 2. 設計與分析分離

傾向分數方法的一個優點：在完全不看結果變項的情況下，先把兩組調整到平衡。平衡達成之後才打開結果。這樣就不可能為了得到想要的結果而反覆修改模型。

請 AI 執行時，明確要求分成兩個階段，第一階段的程式不得讀取結果變項。

### 3. 六個步驟

| 步驟 | 做什麼 | 常見錯誤 |
|---|---|---|
| 1 資料準備 | 處理遺漏；定義處理與結果 | 完整個案刪掉太多人 |
| 2 估計傾向分數 | 以處理為結果的邏輯斯迴歸 | 依 p 值或逐步法選變項；放入中介或結果的後果 |
| 3 配對或加權 | 見下 | 沒有說明估計的對象是誰 |
| 4 平衡診斷 | 標準化差異、分布重疊 | 用 p 值檢查平衡 |
| 5 估計效果 | 在配對或加權後的樣本上比較結果 | 標準誤未考慮配對或權重 |
| 6 敏感度分析 | 未測混淆要多強才能推翻結論 | 省略 |

### 4. 配對

每位處理組的人，找一位傾向分數最接近的對照組的人。

- **卡尺**：兩人傾向分數的差距不得超過某個寬度，常用傾向分數 logit 的 0.2 個標準差（Austin, 2011）。超過就不配對。
- **代價**：配不到對的人被捨棄。結論只適用於配對成功的那群人。
- **估計對象**：處理組的平均效果（ATT），也就是「對那些參加社團的學生而言，社團的效果」。

務必報告：原本兩組各多少人，配對後各剩多少人。

### 5. 加權

不捨棄任何人。每個人依傾向分數給一個權重：處理組 1/e，對照組 1/(1−e)。加權後的樣本中，處理與特徵無關。

- **估計對象**：全體的平均效果（ATE），也就是「如果所有學生都參加，相對於都不參加」。
- **問題**：傾向分數接近 0 或 1 的人權重極大，少數幾個人主導結果。檢查權重的分布；必要時截尾，並報告截尾前後的結果。

配對與加權回答的是不同問題。兩者結果不同，未必是哪一個錯了。

### 6. 平衡診斷

**標準化平均差（SMD）**：兩組平均的差除以合併標準差。一般以小於 0.1 為可接受。

為什麼不用 p 值：p 值隨樣本數變動。配對後樣本變小，p 值自然變大，看起來「沒有顯著差異」，實際上差異可能沒變。SMD 不受樣本數影響。

兩張必備的圖：

- **Love plot**：每個變項調整前後的 SMD。
- **傾向分數分布圖**：兩組的重疊情形。沒有重疊的區域代表正值性不成立，那些人沒有可比的對象。

也不要用傾向分數模型的區辨力評估它的好壞。目的是平衡，不是預測誰參加社團。

### 7. 程式骨架

```r
library(MatchIt); library(cobalt); library(marginaleffects)

# 階段一：設計（不使用結果變項）
m <- matchit(club ~ sex + grade + school_type + urban,
             data = d, method = "nearest",
             distance = "glm", link = "linear.logit",
             caliper = 0.2)
summary(m)                         # 配對前後人數與平衡
love.plot(m, thresholds = c(m = .1))
bal.plot(m, var.name = "distance", which = "both")

# 階段二：分析
md  <- match.data(m)
fit <- glm(regular ~ club, data = md, weights = weights,
           family = quasibinomial)
avg_comparisons(fit, variables = "club",
                vcov = ~subclass, newdata = subset(md, club == 1))
```

加權改用 `WeightIt::weightit(..., method = "glm", estimand = "ATE")`，平衡診斷的函數相同。SAS 對應的程序是 `PROC PSMATCH`。

### 8. 一個需要知道的批評

King 與 Nielsen（2019）指出，傾向分數配對在追求更好的平衡而持續捨棄樣本時，可能反而增加不平衡與對模型的依賴。實務上的回應：設定卡尺後就不再反覆修剪；同時報告加權的結果；考慮直接在共變項上配對的方法。

### 9. AI 在這一步常犯的錯

- 把資料中所有變項放進傾向分數模型，包含中介與結果的後果。
- 用 t 檢定與 p 值報告平衡。
- 配對後沒有報告捨棄了多少人。
- 把配對後的結果稱為「因果效果」而未提未測混淆。
