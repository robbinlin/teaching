## 講授重點

### 1. 兩個模型，兩次機會

到目前為止有兩條路：

- **結果模型**（第 10 週）：對結果建模，調整混淆因子。模型的函數形式要對。
- **處理模型**（第 14 週）：對處理建模，得到傾向分數。傾向分數模型要對。

雙重穩健估計同時使用兩者。只要其中一個模型設定正確，估計就是一致的。最簡單的做法：在加權或配對後的樣本上，再跑一次包含共變項的結果模型。

```r
library(WeightIt); library(marginaleffects)
w   <- weightit(club ~ sex + grade + school_type + urban,
                data = d, method = "glm", estimand = "ATE")
fit <- glm_weightit(regular ~ club * (sex + grade + school_type + urban),
                    data = d, weightit = w, family = binomial)
avg_comparisons(fit, variables = "club")
```

雙重穩健保護的是模型設定錯誤。它不保護未測混淆：兩個模型都少了同一個變項時，兩次機會都是錯的。

### 2. E-value

VanderWeele 與 Ding（2017）提出的問題：一個未測量的混淆因子，要與處理和結果各有多強的關聯，才能把觀察到的關聯完全解釋掉？

以風險比 RR 表示觀察到的關聯（RR > 1）時：

E-value = RR + √(RR × (RR − 1))

| 觀察到的 RR | E-value | 解讀 |
|---|---|---|
| 1.2 | 1.69 | 一個與兩者各有 1.7 倍關聯的未測因子就能解釋 |
| 1.5 | 2.37 | 需要各 2.4 倍 |
| 2.0 | 3.41 | 需要各 3.4 倍 |

E-value 本身不說明結論可不可信。要與已測量的混淆因子比較：資料中最強的混淆因子與處理、結果的關聯是多少？如果「原本的運動興趣」很可能比它更強，而 E-value 只有 1.7，結論就站不住。

對信賴區間靠近 1 的那一端也算一次 E-value。

```r
library(EValue)
evalues.RR(est = 1.5, lo = 1.3, hi = 1.7)
```

### 3. 負對照

找一個理論上不該受處理影響、但會受同樣混淆因子影響的結果。如果分析顯示處理對它也有「效果」，表示混淆沒有處理乾淨。

例：參加運動社團不應該影響「是否近視」。若調整後兩組近視比例仍有差異，就要懷疑有未測的家庭或學校因素。能不能做，取決於資料裡有沒有適合的變項。

### 4. 處理未測混淆的其他設計

傾向分數與迴歸只處理測到的變項。下列設計利用資料的結構來處理沒測到的，各自需要特定條件。

| 設計 | 需要什麼 | 核心假設 | 運動領域的例子 |
|---|---|---|---|
| 差異中之差異 | 處理前後、兩組都有資料 | 若沒有處理，兩組的變化趨勢相同 | 某縣市推行每日運動政策，前後與鄰近縣市比較 |
| 工具變數 | 一個只透過處理影響結果的變項 | 工具與結果之間沒有其他路徑 | 住家到運動場館的距離 |
| 斷點迴歸 | 處理由某個門檻決定 | 門檻兩側的人可比 | 體適能未達門檻者須參加加強課程 |
| 固定效果 | 同一單位多次觀察 | 未測混淆不隨時間改變 | 追蹤資料中同一位學生跨年度的變化 |

主資料集是單一年度的橫斷面調查，這四種設計都用不上。知道它們存在，是為了在設計下一個研究或選擇資料時知道該找什麼。

`happiness_data.csv` 是國家 × 年的追蹤資料，可用來示範固定效果：

```r
library(fixest)
feols(`Life Ladder` ~ `Log GDP per capita` | `Country name` + year,
      data = happy, cluster = ~`Country name`)
```

與不含固定效果的迴歸比較，係數縮小多少。

### 5. 多種方法結果一致，代表什麼

迴歸調整、配對、加權、分層四種方法得到相近的估計，常被當作結論穩健的證據。要注意的是，這四種方法依賴同一個假設：沒有未測混淆。它們調整的是同一組變項。一致只說明結果不受「怎麼調整」影響，不說明調整的變項夠不夠。

真正獨立的佐證來自依賴不同假設的設計，例如上表的任何一種，或負對照。

### 6. 限制段落怎麼寫

限制段落不是道歉，是告訴讀者結論可以用到哪裡。四個要素：

1. 最可能的未測混淆是什麼，方向往哪邊偏。
2. 敏感度分析的結果（E-value 與比較基準）。
3. 資料結構造成的限制（橫斷面、自述、回溯期間）。
4. 在這些限制下，結論能說到哪裡。

不好的寫法：「本研究為橫斷面設計，無法推論因果，未來研究可採縱貫設計。」這句話可以貼在任何一篇論文後面。

較好的寫法：「原本的運動興趣未被測量，它會同時提高參加社團與規律運動的機率，使估計偏高。E-value 為 [__]，而資料中最強的已測混淆因子（性別）與兩者的關聯約為 [__]。我們認為未測的運動興趣很可能強過這個水準，因此本研究的估計應視為社團效果的上限。」
