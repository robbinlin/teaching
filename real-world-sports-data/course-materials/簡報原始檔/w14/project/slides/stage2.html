library(marginaleffects)

md  <- match.data(m)
fit <- glm(regular ~ club, data = md, weights = weights,
           family = quasibinomial)
avg_comparisons(fit, variables = "club",
                vcov = ~subclass,
                newdata = subset(md, club == 1))

加權改用 WeightIt::weightit(..., method = "glm", estimand = "ATE")，平衡診斷的函數相同。SAS 對應的程序是 PROC PSMATCH。
