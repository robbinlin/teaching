階段一：設計

library(MatchIt); library(cobalt)

# 這一段沒有出現結果變項 regular
m <- matchit(club ~ sex + grade + school_type + urban,
             data = d, method = "nearest",
             distance = "glm", link = "linear.logit",
             caliper = 0.2)
summary(m)   # 配對前後人數與平衡
love.plot(m, thresholds = c(m = .1))
bal.plot(m, var.name = "distance", which = "both")

真實世界運動大數據分析　W14

club、sex、grade、school_type 為示意名稱，請替換為編碼簿中的實際變項。逐行說明：matchit 的公式右邊來自 DAG 的調整集；link 設為 linear.logit 讓卡尺以 logit 的標準差為單位；summary 看人數，love.plot 看 SMD 是否都在 0.1 以內，bal.plot 看重疊。
