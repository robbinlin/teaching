表二謬誤

把所有 OR 畫成一張森林圖

proc logistic data=survey4;
  class a1 a5 a6 urban;
  model regular(ref=First) =
    a1 a2 a3 a4 a5 a6
    b13-b21 urban / expb;
run;

課程既有分析：人口學變項、九題體育學習認知與都市化層級，全部放進一個模型。

每個係數調整的變項組合不同。有的調整了自己的中介，有的沒調整自己的混淆。

Westreich 與 Greenland（2013）稱之為表二謬誤。
