彙總的分母

count(*) 與 count(欄位) 算的不是同一群人

select county,
       sum(regular = 1) / count(*) as regular_pct
from survey4
group by county;

count(*)

計算所有列，包含 regular 為遺漏值的人。

count(regular)

只計算 regular 非遺漏的人。

兩者的差別就是「沒回答的人算不算分母」。這個決定寫在規格書裡，不由寫 SQL 的人或模型臨時決定。
