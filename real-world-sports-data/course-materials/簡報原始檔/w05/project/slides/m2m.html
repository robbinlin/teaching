多對多合併

同一份資料，DATA step 與 SQL 的列數不同

課程範例：alfa 與 beta 兩張表，A21 各有一筆，A25 各有三筆。

做法結果列數原因
DATA; MERGE alfa beta; BY id;4同一鍵內依序一對一配對
PROC SQL inner join10同一鍵內兩兩配對：1 + 3×3

多對多幾乎都不是你要的。遇到時先回頭確認：其中一張表的粒度是否弄錯。
