調查權重

未加權描述樣本，加權估計母體

library(survey)
des <- svydesign(ids = ~1, weights = ~wt, data = survey4)
svymean(~regular, des, na.rm = TRUE)
svyby(~regular, ~urban, des, svymean, na.rm = TRUE)

wt 請替換為編碼簿中的權重變項；有分層與叢集變項時一併放入 svydesign。SAS 對應的是 PROC SURVEYFREQ 與 PROC SURVEYMEANS。

AI 幾乎不會主動加權，除非你在規格書中寫明。

真實世界運動大數據分析　W07

加權與未加權差多少，取決於抽樣時各層的抽出率差多少。若釋出資料沒有權重變項與分層資訊，這一頁改為概念說明，作業的加權部分取消。
