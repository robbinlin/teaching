雙重穩健估計

在加權後的樣本上再跑一次結果模型

library(WeightIt); library(marginaleffects)

w   <- weightit(club ~ sex + grade + school_type + urban,
                data = d, method = "glm", estimand = "ATE")
fit <- glm_weightit(
         regular ~ club * (sex + grade + school_type + urban),
         data = d, weightit = w, family = binomial)
avg_comparisons(fit, variables = "club")

保護的是模型設定錯誤，不保護未測混淆。兩個模型都少了同一個變項時，兩次機會都是錯的。

變項名稱為示意，請替換為編碼簿中的實際變項。weightit 是處理模型，glm_weightit 是結果模型並帶入權重。輸出是調整後的比例差。請學生把這個數字與上週單獨加權的結果比較。
