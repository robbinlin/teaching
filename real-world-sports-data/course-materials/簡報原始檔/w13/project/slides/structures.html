DAG 的三種基本結構

結構箭頭關係例子該不該調整
混淆社團 ← 性別 → 運動性別同時影響參加社團與運動習慣要
中介社團 → 運動技能 → 運動社團透過提升技能促進運動不要（若想估總效果）
衝突因子社團 → 校隊 ← 運動參加社團與規律運動都提高入選校隊的機會不要

調整混淆因子去除偏誤。調整中介會把效果的一部分扣掉。調整衝突因子，或只分析它的某一層（例如只看校隊學生），會製造原本不存在的關聯。

真實世界運動大數據分析　W13

DAG 用箭頭畫出你對「誰影響誰」的主張。三列逐一在白板上畫出來，請學生判斷箭頭方向。衝突因子最不直覺：舉「只分析校隊學生」的例子，校隊裡沒參加社團的人多半本來就很常運動，於是社團與運動看起來呈負相關。
