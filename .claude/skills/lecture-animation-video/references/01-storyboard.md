# 01 讀講義、核對數字、寫分鏡

## 取得內容
- pptx：`python3 -c "from pptx import Presentation; ..."` 逐頁抽文字與備忘稿，存成 `scratchpad/chN/slides.txt`。
- 課程網站（ChatGPT／其他平台建站）：用 Playwright 開每一章的 Learn / Example / Practice / Review 頁，
  把文字 `innerText` 存下來。網站常有「更正說明」（例如組合數算錯、百分位對應錯），要採用更正後的值。
- 資料集：網站 datasets 區或講義附檔（csv / sav / sps）。下載到專用空目錄，讀取時用 `python3 -I`。

## 重算所有會出現在畫面上的數字
講義數字只當線索，不當答案。用 pandas / scipy / statsmodels 重算：
- 描述統計、五數總結、直方圖分箱；
- 機率表（邊際／聯合／條件）、二項式／常態機率；
- t、Wilcoxon、Mann–Whitney、ANOVA + Bonferroni、Kruskal–Wallis、卡方（含 Yates）、Fisher、McNemar；
- 相關（Pearson／Spearman）、迴歸係數、R²、Poisson 迴歸（offset = log 人年）。
不符時（例如講義寫 0.235 但單位是公分、應為 5.75）：影片用重算值，分鏡與字幕註明「依資料重算」。

## 故事點要有出處
每集開場用一個真實歷史片段（年代＋人物＋事件），用網頁搜尋查證至少兩個來源，連結寫進分鏡檔「資料來源」。
例：1906 高爾頓猜牛重、1908 戈塞特與健力士、1920 年代女士品茶、1951 辛普森詭論、1805 勒讓德最小平方。
講錯年代比不講故事更糟，查不到就換一個。

## 分鏡檔格式（storyboards/第N章_主題_分鏡.md）
```
# 第N章 主題 — 動畫分鏡（3 支，各約 1.5–2.5 分鐘）
角色：阿統（爸爸）、小檢（媽媽）、小樣（小孩）＋歷史人物（…）
風格：原子筆手繪、紙張質感、線條抖動；繁中字幕；中文男聲旁白；JS 合成配樂。
所有數字皆以講義與課程資料重新計算核對（資料集名稱、n）。

## EP1 標題（約 2 分）
1. 開場故事（年代、人物、一句話衝突）
2. 概念（講義頁碼）
3. 講義例題（數字）
4. 作業（數字）
5. 結語：一句話帶走
## EP2 …
## EP3 …
## 資料來源
- 講義檔名、網站章節
- 每個故事點的 2 個連結
```
每集 5–7 個場景，每場景 1–4 句旁白。一集總字數 350–550 字，唸出來約 2–3 分鐘。

## 分鏡確認
貼給使用者的是摘要（每集標題＋場景一行），附要確認的選項（配音性別／語速／風格）。
使用者回「確認」才開始寫程式。使用者若說「繼續做完」，後續章節不必再逐章等確認，但仍寫分鏡檔並 commit。
