# 第1章 緒論 — 動畫分鏡（6 支：EP0–EP5，各約 1.5–2.5 分鐘）
角色：沿用「阿統／小檢／小樣」或新角色（待確認）＋歷史人物
風格：原子筆手繪、紙張質感、線條抖動；繁中字幕；中文男聲旁白；JS 合成配樂。
EP0 對應新增的 1.0「選題」單元（網站尚未加），EP1–EP5 對應 1.1–1.5 單元；結尾一句話帶出網站上的判斷題與寫作練習。
標題一律用「怎麼做」的問句，學生一看就知道這支要解決什麼。

## EP0 如何選擇研究題目？（對應新增的 1.0）
1. 開場：1979 年，澳洲病理科醫師 Robin Warren 在胃部切片反覆看到彎曲的細菌，當時認為胃酸太強、細菌活不了；他沒放過這個「不合理」的現象（後與 Barry Marshall 合作，2005 年諾貝爾獎）
2. 概念：好題目過三關——重要（有人在乎答案）、做得到（有對象、資料、時間）、有缺口（文獻裡還沒有好答案）
3. 例題：小研從「我喜歡划船」（興趣）→讀文獻→縮小成「大專划船選手的睡眠與疲勞」→三關檢查
4. 反例：「如何提升運動表現？」太大；「研究奧運國手心理狀態」但接觸不到國手，做不出來
5. 作業：列三個候選題目，用三關逐一打分，選一個
6. 結語：好題目，是做得出來的題目

## EP1 研究背景怎麼寫？（對應 1.1）
1. 開場：1898 年，Norman Triplett 注意到自行車選手有人陪騎時速度更快（社會促進研究的起點）
2. 概念：背景像漏斗，現象 → 已知 → 缺口 → 本研究
3. 例題：大專划船選手賽季疲勞監測，四句話排成背景
4. 反例：「我喜歡籃球所以研究籃球」少了什麼
5. 作業：用四步寫出你自己的背景段
6. 結語：缺口句是背景的重心

## EP2 研究問題怎麼寫？（對應 1.2）
1. 開場：1854 年倫敦霍亂，John Snow 把「為什麼死這麼多人」縮成「水源是否與死亡有關」
2. 概念：對象、變項、關係
3. 例題：「運動訓練好不好？」逐步縮小成睡眠時數與疲勞分數
4. 判斷：哪些問句能用資料回答
5. 作業：用句型寫出你的研究問題
6. 結語：能被資料回答，才是研究問題

## EP3 研究目的怎麼設立？（對應 1.3）
1. 開場：1747 年，James Lind 在船上把水手分成六組，各給不同療法（壞血病）
2. 概念：目的是研究問題的陳述版，動詞＋對象＋介入＋結果
3. 例題：把四個片段拼成一句目的
4. 反例：「讓大家更重視運動」為什麼不算目的
5. 作業：寫出兩條目的並對應研究問題
6. 結語：目的要能用結果回答

## EP4 研究假設與名詞定義怎麼寫？（對應 1.4）
1. 開場：1847 年，Ignaz Semmelweis 在維也納產科病房，提出洗手與死亡率的假設
2. 概念：操作型定義三件事：工具、時間點、數值意義
3. 例題：「疲勞」從一個模糊詞變成 Borg CR-10 的分數
4. 假設句：時間 → 組別 → 指標 → 方向
5. 作業：為你的關鍵詞寫操作型定義與假設
6. 結語：好假設能被資料推翻

## EP5 研究範圍與限制怎麼設定？（對應 1.5）
1. 開場：1936 年美國總統選舉前，Literary Digest 民調回收兩百多萬份卻預測錯誤（取樣偏誤）
2. 概念：範圍是選擇的邊界，限制是控制不了的部分
3. 例題：划船選手研究的範圍與限制各一句
4. 反例：「本研究沒有任何限制」「讓全世界選手變強」
5. 作業：寫範圍、限制與重要性
6. 結語：誠實交代邊界，反而更可信
