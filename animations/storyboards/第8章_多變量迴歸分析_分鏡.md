# 第8章 多變項迴歸分析 — 動畫分鏡（3 支）

課堂與作業模型皆以課程網站 CVD_All_spss.csv 重算（n = 64,489；男 24,051、女 40,438，與講義分層人數相符）。講義 p.16–17 的「0.235／0.286」係數與腰圍（公分）尺度不符，影片採重算之公分係數並註明。

## EP1 干擾變數：辛普森詭論與調整
1. 1951 年辛普森的詭論；講義招生例：男 68.8% vs 女 56.5%，分法學院（15.1% vs 33.6%）、商學院（80.1% vs 91.1%）後女生反而都較高 → 合併時方向反轉；1973 柏克萊案例同理。
2. 賀爾蒙治療 vs 冠心病：觀察性研究（護士健康研究）顯示保護 35–60%，2002 年 WHI 隨機試驗反而增加風險 → 「健康使用者」干擾。
3. 課堂模型（重算）：腰圍 ~ 抽菸（≥1 包）：粗估 +5.75 cm；加入年齡（≥50）調整：+5.74 cm，年齡 +6.31 → 調整前後幾乎不變，年齡不是干擾變數（與講義結論相同）。
4. 干擾變數的定義：和暴露有關、也和結果有關、且不在因果路徑上；調整前後估計值差很多才算。
5. 結語。

## EP2 交互作用與分層分析
1. 交互作用：抽菸的效果會不會隨年齡層改變？模型加乘積項 抽菸×年齡。
2. 重算：抽菸 +6.83、年齡 +7.04、交互作用 −2.81（p < 0.001）：50 歲以上抽菸的腰圍增幅較小（6.83 − 2.81 = 4.02）。
3. 三個以上因子交互作用太複雜 → 分層分析：依性別分兩層。女性（n = 38,758）：交互作用 p = 0.20，不顯著；男性（n = 22,409）：交互作用 −1.08，p < 0.001 → 與講義「女性無、男性有」一致。
4. 分層的代價：層內人數變少、檢定力下降。
5. 結語。

## EP3 作業：壓差、年齡、性別與卜瓦松發生率
1. 壓差 = 收縮壓 − 舒張壓，平均 45.2 mmHg；壓差 ~ 年齡：每歲 +0.41（p < 0.001，R² 0.158）。
2. 加入性別：年齡 0.399、男性 +3.63；年齡係數幾乎不變 → 性別不是年齡的干擾變數，但年齡×性別交互作用 −0.149 顯著（男性斜率較緩）。
3. 卜瓦松模型：5,859 件 CVD / 228,765 人年 = 每 1,000 人年 25.6 件；log 連結、追蹤年數當 offset。
4. 壓差的 IRR：粗估 1.025 / mmHg；調整年齡與性別後 1.003（p = 0.0002）→ 年齡是干擾變數；壓差×性別交互作用 p = 0.43，無。
5. 性別分層：女 24.3、男 28.0 / 1,000 人年；壓差 IRR 女 1.002（p = 0.06）、男 1.005（p < 0.001）。
6. 結語：先問干擾、再問交互作用、必要時分層。
