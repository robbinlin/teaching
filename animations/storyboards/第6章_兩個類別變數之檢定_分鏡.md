# 第6章 兩個類別變數之檢定 — 動畫分鏡（3 支）

數字依講義與課程網站 SPS 資料重算：PPHN 表 χ²（葉氏校正）= 0.2459、p = 0.620，與講義表 6-2 相符；其餘為補算。

## EP1 卡方獨立性檢定
1. 1900 年卡爾・皮爾森提出卡方檢定：觀測與期望差多少才算「不獨立」。
2. 講義血清鉀研究：12,209 人追蹤 9 年、1,475 人得糖尿病，低鉀組罹患率 1.64 倍 → 兩個類別變數有沒有關係？
3. 刷卡系統例：主管 55/45、非主管 70/30；若無關，期望值 62.5/37.5；χ² = Σ(O−E)²/E = 4.8，p = 0.028（葉氏校正 4.18、p = 0.041）。
4. PPHN 資料：胎齡 < 34 週 × 死亡，2×2 列聯表 26/86/6/13；χ² = 0.246、p = 0.62 → 無關聯。
5. 結語：卡方看的是「觀測離期望多遠」。

## EP2 小樣本：葉氏校正與費雪精確檢定
1. 1934 年葉慈的連續性校正；1935 年費雪的精確檢定（從女士品茶來）。
2. 撲克牌例：52 張 13 張紅心，抽 6 張出現 2 張紅心，超幾何分布算機率；期望值 1.5 < 5 → 卡方不適用。
3. 作業：慢性疲勞 A 藥 12/3 vs 安慰劑 3/14；有效率 80% vs 18%；期望次數最小 7.0 ≥ 5；χ² = 12.44、p = 0.0004（葉氏 10.06、p = 0.0015）；費雪精確檢定 p = 0.0010 → 藥物有效。
4. 適用條件清單：觀測獨立、類別互斥、期望次數 ≥ 5（否則用費雪）。
5. 結語。

## EP3 大樣本與配對：疫苗資料與 McNemar
1. 講義 2022 年台灣疫苗資料（台大醫師整理，Yahoo 新聞）：未接種 41/1,504,669，一劑 19、兩劑 39、三劑 59；每百萬中重症 27.2、16.5、6.2、4.9。
2. 2×2：未接種 vs 有接種 117/19,482,724（6.0 每百萬）；χ² = 83.7、p < 0.001。
3. 提醒：樣本超大，任何小差異都顯著，要看效果量（4.5 倍）。
4. McNemar (1947)：同一批人前後（配對）的類別資料，只看「改變」的兩格。
5. 結語：獨立 → 卡方／費雪；配對 → McNemar。
