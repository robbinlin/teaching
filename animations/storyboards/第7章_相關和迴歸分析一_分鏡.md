# 第7章 相關和迴歸分析（一）— 動畫分鏡（3 支）

數字以課程網站 CVD_All_spss.csv 重算：收縮壓～年齡 R² = 0.1767、年齡 50 預測 125.29，與講義圖 7-4 相符；收縮壓～舒張壓 R² = 0.552 相符。散佈圖各取 300 筆隨機子樣本繪製。

## EP1 相關係數：兩個連續變數的關係
1. 1886 年高爾頓量父母與子女身高，發現「回歸到平庸」；1888 年提出「相關」；皮爾森把它寫成相關係數 r。
2. 講義：基隆社區篩檢資料，收縮壓與年齡的散佈圖（300 筆子樣本），r = 0.42。
3. r 從 −1 到 1 的雲形：五張小圖。
4. 講義表 7-2 年齡那一列：腰圍 0.347、收縮壓 0.420、舒張壓 0.256、血糖 0.220、高密度脂蛋白 −0.012、三酸甘油脂 0.129（n ≈ 59,000，p < 0.001）。
5. 結語：r 只量「線性」關係，顯著不等於很強。

## EP2 斯皮爾曼等級相關與極端值
1. 1904 年斯皮爾曼：把數值換成名次再算相關。
2. 講義表 7-4：收縮壓與其他變數的斯皮爾曼係數（腰圍 0.458、舒張壓 0.742、三酸甘油脂 0.322…）與皮爾生比較。
3. 講義圖 7-3 的示範（模擬）：30 個 r ≈ 0 的點加入一個右上角極端點，皮爾生從 −0.17 跳到 0.59，斯皮爾曼只從 −0.17 變成 −0.06。
4. 結語：非常態、非線性、有極端值 → 斯皮爾曼。

## EP3 簡單線性迴歸與作業
1. 1805 年勒讓德的最小平方法：讓殘差平方和最小的那條線。
2. 講義表 7-5：收縮壓 = 93.79 + 0.63 × 年齡；年齡 50 → 125.29（圖 7-4）；斜率顯著但 R² = 0.1767。
3. 收縮壓對舒張壓：R² = 0.552，點更貼近直線 → 決定係數的意義。
4. 作業（無心血管疾病者 n = 56,612）：皮爾生 0.428、斯皮爾曼 0.458；收縮壓 = 58.51 + 0.819 × 腰圍，R² = 0.183；腰圍 100 cm → 平均 140.4 mmHg；平均預測 vs 個別預測。
5. 結語。
