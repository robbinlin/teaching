本集重點
・Anscombe（1973）的四組資料：平均、變異數、相關係數、迴歸線幾乎相同，圖形完全不同。先要分布和圖，再要模型。
・表一列出每個變項的遺漏人數，百分比註明分母：同一個選項，分母不同是 50.3% 或 51.4%。
・被標出的極端值可能是輸入錯誤、遺漏碼或真實的極端值，只有前兩種該處理；刪除之前回到原始紀錄確認。
・未加權的比例描述樣本，加權的比例估計母體；報告要寫明有沒有加權。
・六個都市化層級的規律運動比例 47.0% 到 54.7%：縱軸從 0 開始幾乎一樣高，從 45 開始看起來差 4.8 倍，實際只差 7.7 個百分點。
・請 AI 畫圖時要它同時交出摘要表，從圖上任取一個數字和表格核對。
